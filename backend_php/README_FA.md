# راهنمای جامع راه‌اندازی سامانه مدیریت ویزیت فروشگاهی روی سرور لینوکس (PHP)

این راهنما برای شما و دوستتان تهیه شده تا بتوانید بدون کوچک‌ترین پیچیدگی، کل سامانه را روی هر سرور لینوکسی (شامل هاست‌های cPanel، دایرکت‌ادمین، پلسک یا سرور مجازی اختصاصی Ubuntu/Debian/CentOS) بالا بیاورید.

---

## 🚀 روش ۱: سریع‌ترین راه (هاست‌های اشتراکی و cPanel / DirectAdmin)

1. **دانلود فایل زیپ آماده:**
   فایل `field_sales_php_deployment.zip` را دانلود کنید.
2. **آپلود در سرور:**
   وارد کنترل‌پنل سرور لینوکس (مثلاً cPanel) شوید و به بخش **File Manager** بروید.
3. **استخراج در پوشه اصلی سایت:**
   وارد پوشه `public_html` (یا ساب‌دامین مدنظرتان) شوید و فایل زیپ را **Extract (آنزیپ)** کنید.
4. **تنظیم سطح دسترسی (Permissions):**
   برای اینکه پایگاه داده بتواند ویزیت‌های جدید را ذخیره کند، دسترسی پوشه یا فایل دیتابیس باید قابل نوشتن (Writable) باشد:
   - به پوشه یا فایل `field_sales.db` دسترسی `775` یا `777` بدهید.
5. **تمام شد!**
   سایت را در مرورگر باز کنید. برنامه با نقشه، ثبت ویزیت، نمونه آبی، فیلد تعداد کالا، نمودار ۷ روزه و خروجی اکسل بلافاصله کار می‌کند!

---

## ⚙️ نیازمندی‌های سرور (Server Requirements)

- **نسخه PHP:** نسخه 7.4 یا 8.0 یا 8.1 یا 8.2 یا 8.3
- **اکستنشن‌های فعال PHP:**
  - `pdo` (به صورت پیش‌فرض در ۹۹٪ سرورها فعال است)
  - `pdo_sqlite` (پیش‌فرض لینوکس) یا `pdo_mysql` (در صورت انتخاب دیتابیس MySQL)
  - `json` و `mbstring`

---

## 🐧 روش ۲: راه‌اندازی روی سرور مجازی لینوکس (Ubuntu / Debian VPS)

اگر دوستتان از سرور اختصاصی لینوکسی خام استفاده می‌کند، اجرای این چند دستور کافی است:

```bash
# ۱. به‌روزرسانی مخازن
sudo apt update

# ۲. نصب وب‌سرور آپاچی و پی‌اچ‌پی با ماژول SQLite
sudo apt install -y apache2 php php-sqlite3 php-mbstring libapache2-mod-php

# ۳. فعال‌سازی ماژول rewrite آپاچی
sudo a2enmod rewrite headers
sudo systemctl restart apache2

# ۴. کپی فایل‌های پروژه در مسیر آپاچی
sudo cp -r * /var/www/html/

# ۵. تنظیم مالکیت و دسترسی برای وب‌سرور
sudo chown -R www-data:www-data /var/www/html/
sudo chmod -R 775 /var/www/html/

# ۶. باز کردن پورت ۸۰ در فایروال در صورت نیاز
sudo ufw allow 80/tcp
```

## 🗄️ سوئیچ به دیتابیس MySQL (اختیاری)

به‌صورت پیش‌فرض برنامه با **SQLite** کار می‌کند که نیازی به ساخت کاربر و دیتابیس ندارد و تمام اطلاعات در یک فایل `field_sales.db` نگهداری می‌شود.
اما اگر دوست شما تمایل دارد از **MySQL** استفاده کند:

1. فایل `index.php` را با ویرایشگر باز کنید.
2. در خطوط اولیه، مقدار `DB_DRIVER` را تغییر دهید:
```php
define('DB_DRIVER', 'mysql');
define('MYSQL_HOST', 'localhost');
define('MYSQL_DBNAME', 'نام_دیتابیس_شما');
define('MYSQL_USER', 'نام_کاربری_شما');
define('MYSQL_PASSWORD', 'رمز_عبور_شما');
```
جداول پایگاه داده در اولین اجرا به‌صورت خودکار ایجاد خواهند شد.

## 📡 آدرس‌های API در دسترس

- `GET /api/visits` : دریافت لیست تمام ویزیت‌ها
- `POST /api/visits` : ثبت ویزیت جدید (شامل فیلدهای فروش، نمونه آبی، تعداد کالا و مختصات)
- `POST /api/visits/sync` : همگام‌سازی دسته‌ای آفلاین
- `PUT /api/visits/{id}` : ویرایش مشخصات فروشگاه
- `DELETE /api/visits/{id}` : حذف دائمی ویزیت
- `GET /api/export-excel` : تولید و دانلود گزارش رسمی اکسل راست‌به‌چپ (RTL) به زبان فارسی
